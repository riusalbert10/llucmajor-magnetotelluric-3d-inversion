🎯 What is ModEM Doing?

ModEM (Modular System for Inversion of Electromagnetic Geophysical Data) is solving an inverse problem to find the underground electrical resistivity structure that best explains your electromagnetic field measurements.


The Challenge: Given electromagnetic field measurements at the surface (your 40 stations), determine the 3D resistivity structure underground (your 224,450 cell model).


The Method: Non-Linear Conjugate Gradient (NLCG) iterative optimization

Initial Forward Solution

⏱️ 6-8 hours

Calculate what electromagnetic fields would be measured at your 40 stations if the subsurface really had the initial model (100 Ω·m everywhere).

📐 The Math

Solve Maxwell's equations for each frequency and polarization:

∇ × E = iωμH (Faraday's law)

∇ × H = σE (Ampere's law)

Where: E = electric field, H = magnetic field, σ = conductivity (1/ρ), ω = angular frequency

For each of 58 frequencies:
  • For each polarization (2 modes: X and Y)
  • Solve finite-difference equations on 224,450 cells
  • Apply divergence correction (iterative solver, ~10-40 iterations)
  • Extract fields at 40 station locations
  • Compute impedance tensor: Z = E/H

Calculate Initial RMS Misfit

⏱️ ~1 minute

Compare predicted data (from forward solution) with observed data to quantify how well the initial model fits.

📊 RMS Calculation

RMS = √[ Σ((d_obs - d_pred)² / error²) / N ]

Where:
• d_obs = your measured impedances
• d_pred = impedances from forward model
• error = measurement uncertainty
• N = total number of data points

Goal: RMS ≈ 1.0 (model fits data within uncertainties)

⚠️ Initial RMS is typically 10-50 because the homogeneous starting model (100 Ω·m everywhere) doesn't capture the real subsurface structure. The inversion will reduce this.
3

Sensitivity Calculation (JT)

⏱️ 6-8 hours

Calculate how sensitive each data point is to changes in each model cell. This tells us which parts of the model affect which measurements.

🧮 The Jacobian Matrix

J is a matrix where J[i,j] = ∂d[i]/∂m[j]

• Size: (9,280 data) × (224,450 model parameters) - Too big to store!
• Instead: Compute JTr (transpose times residual vector)
• Method: Adjoint (transpose) forward solves

For each of 58 frequencies:
  • For each polarization (2 modes)
  • Solve the transpose (TRN) problem: same equations but with adjoint source
  • Extract sensitivity to model parameters

NLCG Inversion Iterations

⏱️ 1-3 DAYS (30-90 min per iteration)

Iteratively update the resistivity model to reduce the misfit between observed and predicted data.

🔁 NLCG Algorithm

mk+1 = mk + αkpk

Where:
• mk = current model
• pk = search direction (conjugate gradient)
• αk = step length (line search)
• Includes regularization to keep model smooth

Each NLCG Iteration:
  • 1. Compute gradient using sensitivities from Phase 3
  • 2. Apply model covariance (smoothing constraints)
  • 3. Determine search direction (conjugate gradient)
  • 4. Line search: test different step sizes
  • 5. Update model: m_new = m_old + step × direction
  • 6. Compute new forward solution (repeat Phase 1)
  • 7. Calculate new RMS
  • 8. Check convergence
