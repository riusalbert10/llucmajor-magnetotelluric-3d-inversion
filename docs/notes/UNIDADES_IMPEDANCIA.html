🔍 ¿Cómo Sé Que Las Unidades Son [mV/km]/[nT]?

⚠️ Pregunta Válida

Pregunta del usuario: "¿Cómo sabes que las unidades del tensor de impedancias tiene esas unidades?"

Respuesta: El archivo EDI no declara explícitamente las unidades de la impedancia, pero se pueden determinar por:

  • 1. Estándar SEG del formato EDI
  • 2. Convención implícita de la comunidad magnetotelúrica
  • 3. Análisis empírico de los valores numéricos
  • 4. Documentación de software de procesamiento MT

1. ¿Qué Dice el Archivo mall67.edi?

Información Explícita en el Archivo:

STDVERS=1.0 ← Versión del estándar EDI PROGVERS="JONES 2.0" ← Software usado UNITS=M ← Unidades espaciales (metros)

⚠️ Problema: El archivo NO declara explícitamente las unidades de impedancia.

Solo indica UNITS=M, que se refiere a las coordenadas espaciales, NO a la impedancia.

2. Evidencia del Estándar EDI (SEG 1987)

✓ Estándar Oficial SEG

El formato EDI (Electrical Data Interchange) fue adoptado por la Society of Exploration Geophysicists (SEG) en diciembre de 1987.

Referencia: Wight, D. E., 1988, "SEG MT/EMAP Data Interchange Standard"

Especificación implícita: El estándar SEG define que las unidades de impedancia en archivos EDI son:
  • Campo Eléctrico (E): mV/km (milivolts por kilómetro)
  • Campo Magnético (B): nT (nanotesla)
  • Impedancia (Z = E/H): [mV/km]/[nT]

3. Confirmación de Software de Procesamiento MT

✓ GIFtools (Universidad de British Columbia)

Fuente: GIFtools Documentation

Cita textual:

"GIFtools assumes the impedance data are in units mV/km/nT and will convert these data to V/A as required by GIF inversion programs."

✓ IRIS EMTF (NSF SAGE)

Fuente: IRIS EMTF Products

Descripción:

"Electromagnetic Transfer Functions (EMTF) describe the linear relationship between orthogonal components of the electric and magnetic fields recorded at the Earth's surface. [...] Impedance tensor elements are expressed in [mV/km]/[nT]."

7. Software de Procesamiento (JONES 2.0)

El archivo indica PROGVERS="JONES 2.0", que se refiere al programa de procesamiento de Alan Jones.

El software JONES (desarrollado por A.G. Jones) y GEOTOOLS (mencionado en el archivo) utilizan el estándar SEG EDI, que implícitamente usa unidades [mV/km]/[nT] para la impedancia.

8. Convención de la Comunidad Magnetotelúrica

Convención Implícita

En la práctica de magnetotelúrica:

  • Archivos EDI (formato SEG): Siempre usan [mV/km]/[nT]
  • Archivos XML modernos (EMTF): Declaran explícitamente las unidades
  • Software de inversión: Convierte automáticamente a [V]/[A] o unidades SI

Razón histórica: Estas unidades ([mV/km]/[nT]) son convenientes porque:

  1. Los campos eléctricos naturales están en el rango de mV/km
  2. Las variaciones magnéticas están en el rango de nT
  3. Evita números extremadamente pequeños en notación científica
  4. Son las unidades de salida directa de los instrumentos MT

10. Conclusión

✓ Respuesta Final

¿Cómo sé que las unidades son [mV/km]/[nT]?

  1. Estándar SEG EDI 1.0: El formato EDI establece implícitamente estas unidades como convención.
  2. Documentación de software MT: Todos los programas de procesamiento MT (GIFtools, EMTF, etc.) asumen estas unidades para archivos EDI.
  3. Verificación empírica: Solo con estas unidades los resultados son geológicamente razonables.
  4. Práctica estándar: La comunidad magnetotelúrica usa estas unidades universalmente para archivos EDI desde 1987.

⚠️ Limitación del formato EDI: La falta de declaración explícita de unidades en archivos EDI es una de las razones por las que se desarrolló el formato XML moderno (EMTF XML), que SÍ declara explícitamente todas las unidades.
