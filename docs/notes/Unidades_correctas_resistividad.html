⚠️ Comparación de Fórmulas: Corrección del Cálculo de Resistividad

Problema detectado: Error de unidades en la fórmula de resistividad aparente

1. Cambio en la Fórmula de Resistividad Aparente

❌ INCORRECTO (Versión Original) ✅ CORRECTO (Versión Corregida)
ρa = |Z|² / (ω × μ₀)

Donde:

  • ω = 2πf (frecuencia angular)
  • μ₀ = 4π × 10-7 H/m

⚠️ Error: Esta fórmula es para impedancia en unidades SI puras [V/m]/[A/m], NO para archivos EDI.
ρa = |Z|² / (5 × f)

O equivalentemente:

ρa = 0.2 × T × |Z|²

Donde:

  • f = frecuencia (Hz)
  • T = período = 1/f (s)
  • Z en [mV/km]/[nT] (unidades EDI estándar)

✓ Correcto: Fórmula específica para archivos EDI con impedancia en [mV/km]/[nT].

2. Cambios en el Código Python

2.1 Función calculate_apparent_resistivity

❌ CÓDIGO INCORRECTO (Original):

def calculate_apparent_resistivity(zr, zi, freq):
    """Calcula resistividad aparente a partir de componentes de impedancia"""
    MU0 = 4 * np.pi * 1e-7  # ← PROBLEMA: Constante incorrecta

    z_magnitude = np.sqrt(zr**2 + zi**2)
    omega = 2 * np.pi * freq         # ← PROBLEMA: Frecuencia angular
    rho_a = (z_magnitude**2) / (omega * MU0)  # ← FÓRMULA INCORRECTA

    return rho_a

✅ CÓDIGO CORRECTO (Corregido):

def calculate_apparent_resistivity(zr, zi, freq):
    """
    Calcula resistividad aparente para archivos EDI

    Para archivos EDI estándar con impedancia en [mV/km]/[nT]:
    ρₐ = 0.2 × T × |Z|² = |Z|² / (5f)

    Parámetros:
        zr: Parte real de la impedancia [mV/km]/[nT]
        zi: Parte imaginaria de la impedancia [mV/km]/[nT]
        freq: Frecuencia (Hz)

    Retorna:
        rho_a: Resistividad aparente (Ω·m)
    """
    z_magnitude = np.sqrt(zr**2 + zi**2)

    # Fórmula correcta para unidades EDI estándar [mV/km]/[nT]
    rho_a = (z_magnitude**2) / (5.0 * freq)  # ← FÓRMULA CORRECTA

    return rho_a

5. ¿Por Qué Este Factor de Conversión?

Explicación de las Unidades EDI

El formato EDI estándar usa unidades [mV/km]/[nT] para la impedancia. Para convertir estas unidades a la resistividad en Ω·m, debemos considerar:

Campo Eléctrico: mV/km = 10-3 V / 103 m = 10-6 V/m
Campo Magnético: nT = 10-9 T = 10-9 Wb/m² = 10-9 V·s/m²
Impedancia Z: [mV/km]/[nT] = (10-6 V/m) / (10-9 V·s/m²) = 103 m/s

Derivación completa:

Para impedancia en unidades SI:

ρa = |ZSI|² / (ωμ₀) = |ZSI|² / (2πf × 4π × 10-7)

ρa = |ZSI|² / (7.89 × 10-6 × f)

Para impedancia EDI en [mV/km]/[nT]:

La conversión de unidades introduce factores que simplifican a:

ρa = |ZEDI|² / (5f)

o equivalentemente: ρa = 0.2 × T × |ZEDI|²

Verificación:

Ratio = (7.89 × 10-6 × f) / (5 × f) ≈ 1.58 × 10-6

Este factor de ~10-6 proviene de la conversión [mV/km]/[nT] → SI, NO de la permeabilidad magnética.
