Smooth 1D MT Inversion with Levenberg-Marquardt Algorithm

Overview

This document provides a comprehensive mathematical explanation of the Smooth 1D Magnetotelluric Inversion method implemented using the Levenberg-Marquardt algorithm with smoothness constraints.

Purpose: To find a smooth 1D resistivity model that optimally fits observed magnetotelluric data while minimizing model complexity.

Key Concept: This is a regularized nonlinear least-squares problem where we balance data fit (minimize misfit) against model roughness (maximize smoothness).

1. The Inverse Problem

1.1 Problem Statement

Given observed apparent resistivities \(\rho_{\text{obs}}(T_i)\) at \(N\) periods \(T_i\), find a layered Earth model with \(M\) layers having resistivities \(\rho_j\) and thicknesses \(h_j\) such that:

$$\rho_{\text{synthetic}}(T_i; \mathbf{m}) \approx \rho_{\text{obs}}(T_i)$$

where \(\mathbf{m} = [\rho_1, \rho_2, \ldots, \rho_M]^T\) is the model vector containing layer resistivities.

1.2 The Forward Problem

The forward operator \(\mathcal{F}\) maps the model space to the data space:

$$\mathbf{d}_{\text{pred}} = \mathcal{F}(\mathbf{m})$$

where \(\mathbf{d}_{\text{pred}} = [\rho_{\text{synthetic}}(T_1), \ldots, \rho_{\text{synthetic}}(T_N)]^T\)

The forward modeling uses Wait's recursion algorithm (see Section 2).

2. Wait's Recursion Algorithm

2.1 Electromagnetic Wave Propagation in Layered Media

For a 1D layered Earth, the impedance at the surface can be calculated by recursion starting from the deepest layer.

2.2 Surface Impedance Calculation

Step 1: Start with the impedance of the infinite half-space (bottom layer):

$$Z_M = \sqrt{i \omega \mu_0 \rho_M}$$

where:

  • \(\omega = 2\pi/T\) is the angular frequency
  • \(\mu_0 = 4\pi \times 10^{-7}\) H/m is the magnetic permeability
  • \(\rho_M\) is the resistivity of the half-space

Step 2: For each layer \(j = M-1, M-2, \ldots, 1\), calculate the impedance recursively:

$$k_j = \sqrt{\frac{i\omega\mu_0}{\rho_j}}$$ $$Z_{0,j} = \sqrt{i\omega\mu_0\rho_j}$$ $$r_j = \frac{Z_{j+1} - Z_{0,j}}{Z_{j+1} + Z_{0,j}}$$ $$Z_j = Z_{0,j} \frac{1 + r_j e^{-2k_j h_j}}{1 - r_j e^{-2k_j h_j}}$$

where:

  • \(k_j\) is the complex wavenumber in layer \(j\)
  • \(Z_{0,j}\) is the intrinsic impedance of layer \(j\)
  • \(r_j\) is the reflection coefficient at interface \(j\)
  • \(h_j\) is the thickness of layer \(j\)

2.3 Apparent Resistivity Calculation

Once the surface impedance \(Z_1\) is calculated, the apparent resistivity is:

$$\rho_a(T) = \frac{1}{\omega\mu_0} |Z_1|^2 = \frac{T}{2\pi\mu_0} |Z_1|^2$$
Key Point: This forward calculation is nonlinear in the model parameters \(\rho_j\), which is why we need iterative optimization methods like Levenberg-Marquardt.

3. The Objective Function

3.1 Data Misfit Term

The data misfit measures how well the model fits the observed data. We work in logarithmic space because resistivity spans many orders of magnitude:

$$\Phi_d(\mathbf{m}) = \sum_{i=1}^{N} \left[ \log_{10}\rho_{\text{obs}}(T_i) - \log_{10}\rho_{\text{synthetic}}(T_i; \mathbf{m}) \right]^2$$

This can be written in vector form:

$$\Phi_d(\mathbf{m}) = \|\mathbf{r}(\mathbf{m})\|^2 = \mathbf{r}^T \mathbf{r}$$

where \(\mathbf{r}(\mathbf{m})\) is the residual vector:

$$r_i(\mathbf{m}) = \log_{10}\rho_{\text{obs}}(T_i) - \log_{10}\rho_{\text{synthetic}}(T_i; \mathbf{m})$$

3.2 Smoothness Constraint (Regularization)

To prevent overfitting and oscillatory models, we add a smoothness penalty that penalizes rapid changes in resistivity:

$$\Phi_s(\mathbf{m}) = \|\mathbf{L}\mathbf{m}\|^2 = \sum_{j=1}^{M-2} \left[ m_{j+2} - 2m_{j+1} + m_j \right]^2$$

where \(m_j = \log_{10}\rho_j\) and \(\mathbf{L}\) is the second-difference operator (discrete second derivative):

$$\mathbf{L} = \begin{bmatrix} 1 & -2 & 1 & 0 & \cdots & 0 \\ 0 & 1 & -2 & 1 & \cdots & 0 \\ \vdots & \vdots & \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \cdots & 1 & -2 & 1 \end{bmatrix}$$
Physical Interpretation: The second derivative measures the curvature of the resistivity profile. Minimizing \(\Phi_s\) enforces a smooth, minimally-structured model.

3.3 Combined Objective Function

The total objective function balances data fit and smoothness:

$$\Phi(\mathbf{m}) = \Phi_d(\mathbf{m}) + \lambda \Phi_s(\mathbf{m})$$

where \(\lambda\) is the regularization parameter (smoothness weight):

  • \(\lambda = 0\): No smoothness constraint (may overfit)
  • \(\lambda \to \infty\): Maximum smoothness (may underfit)
  • Typical value: \(\lambda = 1-10\) (balances fit and smoothness)

In vector form for Levenberg-Marquardt:

$$\mathbf{f}(\mathbf{m}) = \begin{bmatrix} \mathbf{r}(\mathbf{m}) \\ \sqrt{\lambda} \mathbf{L}\mathbf{m} \end{bmatrix}$$

The optimization problem becomes:

$$\mathbf{m}^* = \arg\min_{\mathbf{m}} \|\mathbf{f}(\mathbf{m})\|^2$$

4. Levenberg-Marquardt Algorithm

4.1 Trust-Region Framework

The Levenberg-Marquardt (LM) algorithm solves nonlinear least-squares problems by combining:

  • Gauss-Newton (fast near solution)
  • Gradient Descent (robust far from solution)
Key Idea: At each iteration, solve a local quadratic approximation within a "trust region" where the approximation is valid.

4.2 Linear Approximation

At iteration \(k\), approximate the objective function by a quadratic model:

$$\mathbf{f}(\mathbf{m}_k + \mathbf{p}) \approx \mathbf{f}(\mathbf{m}_k) + \mathbf{J}_k \mathbf{p}$$

where \(\mathbf{J}_k\) is the Jacobian matrix:

$$J_{ij} = \frac{\partial f_i}{\partial m_j} = \frac{\partial}{\partial m_j} \left[ \log_{10}\rho_{\text{obs}}(T_i) - \log_{10}\rho_{\text{synthetic}}(T_i; \mathbf{m}) \right]$$

4.3 The LM Update Step

Find the step \(\mathbf{p}\) by solving the damped normal equations:

$$\left( \mathbf{J}_k^T \mathbf{J}_k + \mu_k \mathbf{I} \right) \mathbf{p}_k = -\mathbf{J}_k^T \mathbf{r}(\mathbf{m}_k)$$

where:

  • \(\mu_k > 0\) is the damping parameter
  • \(\mathbf{I}\) is the identity matrix

Update the model:

$$\mathbf{m}_{k+1} = \mathbf{m}_k + \mathbf{p}_k$$

4.4 Damping Parameter Strategy

The damping parameter \(\mu_k\) controls the algorithm behavior:

\(\mu_k\) Value Behavior When Used
\(\mu_k \to 0\) Pure Gauss-Newton Near minimum (quadratic convergence)
\(\mu_k\) moderate Hybrid approach Normal operation
\(\mu_k\) large Gradient descent Far from minimum (robust)

Adaptive damping:

$$\mu_{k+1} = \begin{cases} \mu_k / \beta & \text{if } \Phi(\mathbf{m}_{k+1}) < \Phi(\mathbf{m}_k) \quad \text{(good step)} \\ \mu_k \times \beta & \text{if } \Phi(\mathbf{m}_{k+1}) \geq \Phi(\mathbf{m}_k) \quad \text{(bad step)} \end{cases}$$

where \(\beta \approx 10\) is the adjustment factor.

4.5 Algorithm Pseudocode

Algorithm: Levenberg-Marquardt with Smoothness Constraint Input: - Observed data: \(\mathbf{d}_{\text{obs}}\) - Initial model: \(\mathbf{m}_0\) - Smoothness weight: \(\lambda\) - Initial damping: \(\mu_0\) Initialize: k = 0 \(\mathbf{m} = \mathbf{m}_0\) \(\mu = \mu_0\) Repeat until convergence: 1. Compute forward response: \(\mathbf{d}_{\text{pred}} = \mathcal{F}(\mathbf{m}_k)\) 2. Compute residuals: \(\mathbf{r} = \log_{10}(\mathbf{d}_{\text{obs}}) - \log_{10}(\mathbf{d}_{\text{pred}})\) 3. Compute Jacobian: \(\mathbf{J}_k\) 4. Augment for smoothness: \(\tilde{\mathbf{J}} = \begin{bmatrix} \mathbf{J}_k \\ \sqrt{\lambda}\mathbf{L} \end{bmatrix}\) \(\tilde{\mathbf{r}} = \begin{bmatrix} \mathbf{r} \\ \sqrt{\lambda}\mathbf{L}\mathbf{m}_k \end{bmatrix}\) 5. Solve for step: \((\tilde{\mathbf{J}}^T\tilde{\mathbf{J}} + \mu_k\mathbf{I})\mathbf{p}_k = -\tilde{\mathbf{J}}^T\tilde{\mathbf{r}}\) 6. Trial model: \(\mathbf{m}_{\text{trial}} = \mathbf{m}_k + \mathbf{p}_k\) 7. Evaluate: \(\Phi_{\text{trial}} = \|\mathbf{f}(\mathbf{m}_{\text{trial}})\|^2\) 8. If \(\Phi_{\text{trial}} < \Phi_k\): (good step) \(\mathbf{m}_{k+1} = \mathbf{m}_{\text{trial}}\) \(\mu_{k+1} = \mu_k / 10\) Else: (bad step) \(\mathbf{m}_{k+1} = \mathbf{m}_k\) \(\mu_{k+1} = \mu_k \times 10\) Reject step, retry 9. Check convergence: If \(\|\mathbf{p}_k\| < \epsilon_x\) or \(\Phi_{k+1} < \epsilon_f\): Break 10. k = k + 1 Output: Optimized model \(\mathbf{m}^*\)

5. Layer Structure and Depth Discretization

5.1 Logarithmic Layer Spacing

The model uses logarithmically-spaced layers to match the physics of electromagnetic diffusion:

$$z_j = 10^{\alpha_j}, \quad \alpha_j = \log_{10}(z_{\min}) + \frac{j-1}{M-1}[\log_{10}(z_{\max}) - \log_{10}(z_{\min})]$$

where:

  • \(z_j\) is the depth to the top of layer \(j\)
  • \(z_{\min} = 10\) m (shallowest layer)
  • \(z_{\max}\) = maximum investigation depth (typically 3× max skin depth)
  • \(M = 30\) is the number of layers
Why logarithmic? Electromagnetic fields decay exponentially with depth. Logarithmic spacing provides:
  • Fine resolution near surface (high-frequency sensitivity)
  • Coarse resolution at depth (low-frequency sensitivity)
  • Matches natural resolution of MT method

5.2 Layer Thicknesses

Layer thicknesses are computed from layer tops:

$$h_j = z_{j+1} - z_j, \quad j = 1, 2, \ldots, M-1$$ $$h_M = \infty \quad \text{(half-space)}$$

5.3 Maximum Investigation Depth

The maximum depth is automatically determined from skin depth:

$$\delta(T) = 503 \sqrt{\frac{\rho_a(T)}{f}} = 503 \sqrt{\rho_a(T) \cdot T}$$ $$z_{\max} = \min(3 \times \max[\delta(T)], \, 50\,\text{km})$$

This ensures the model extends deep enough to capture all data sensitivity.

6. RMS Misfit Calculation

6.1 Definition

The Root Mean Square (RMS) misfit quantifies the goodness of fit:

$$\text{RMS} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} \left[ \log_{10}\rho_{\text{obs}}(T_i) - \log_{10}\rho_{\text{synthetic}}(T_i) \right]^2}$$

This is equivalent to the standard deviation of the logarithmic misfit.

6.2 Interpretation

RMS Value Interpretation Quality
RMS < 0.1 Excellent fit (within ~25% on average) ✓✓✓ Excellent
0.1 ≤ RMS < 0.3 Good fit (within ~2× on average) ✓✓ Good
0.3 ≤ RMS < 0.5 Acceptable fit (within ~3× on average) ✓ Acceptable
RMS ≥ 0.5 Poor fit (order of magnitude errors) ✗ Poor

6.3 Why Logarithmic RMS?

Working in log space is essential because:

  1. Resistivity spans 4-6 orders of magnitude (0.1 to 10000 Ω·m)
  2. Errors are typically proportional to magnitude (multiplicative, not additive)
  3. Log space treats 10 vs 100 Ω·m the same as 100 vs 1000 Ω·m
  4. Matches the scale of measurement uncertainties
$$\text{Relative Error} = 10^{\text{RMS}} - 1$$

For example:

  • RMS = 0.1 → ~26% average relative error
  • RMS = 0.3 → ~100% average relative error (factor of 2)
  • RMS = 0.5 → ~216% average relative error (factor of 3.16)

7. Comparison: Bostick vs Smooth Inversion

Bostick Transformation

Type: Analytical approximation

Formula:

$$\rho_{\text{Bostick}} = \rho_a \left(1 + \frac{d\ln\rho_a}{d\ln T}\right)$$ $$z_{\text{Bostick}} = \frac{1}{\sqrt{2}} \cdot 503\sqrt{\rho_a T}$$

Advantages:

  • ✓ Extremely fast (1 second)
  • ✓ No iterations required
  • ✓ Good first approximation
  • ✓ Stable and robust

Limitations:

  • ✗ Not optimized to fit data
  • ✗ Can be rough/oscillatory
  • ✗ No formal uncertainty estimation
  • ✗ Approximate depth calculation

Best for:

  • Quick reconnaissance
  • Initial model for inversion
  • Quality control

Smooth Inversion (LM)

Type: Regularized optimization

Objective:

$$\min_{\mathbf{m}} \left\{ \|\log\rho_{\text{obs}} - \log\rho_{\text{syn}}(\mathbf{m})\|^2 + \lambda\|\mathbf{L}\mathbf{m}\|^2 \right\}$$

Advantages:

  • ✓ Optimally fits data (minimizes RMS)
  • ✓ Smooth, geologically reasonable models
  • ✓ Controlled by smoothness parameter
  • ✓ Provides uncertainty estimates
  • ✓ Physically accurate depths

Limitations:

  • ✗ Slower (1-3 minutes per station)
  • ✗ Requires iterations (typically 10-50)
  • ✗ May need good starting model
  • ✗ Sensitive to smoothness weight

Best for:

  • Final interpretation
  • Publication-quality models
  • Quantitative analysis

7.1 Expected Relationship

General Rule: Smooth inversion RMS ≤ Bostick RMS

Because smooth inversion explicitly minimizes the data misfit, it should always achieve equal or better fit than Bostick (which doesn't optimize fit).

Typical improvements:

  • Simple 1D structure: 10-30% RMS improvement
  • Moderate complexity: 30-50% RMS improvement
  • Complex structure: 50-70% RMS improvement

8. Implementation Details

8.1 Python Implementation

The implementation uses scipy.optimize.least_squares with Trust Region Reflective algorithm:

result = least_squares( objective_function, initial_model, bounds=(log10(0.1), log10(10000)), # Physical bounds method='trf', # Trust Region Reflective ftol=1e-6, # Function tolerance xtol=1e-6, # Parameter tolerance max_nfev=50 * n_layers, # Max function evaluations verbose=0 )

8.2 Logarithmic Parameterization

The optimization works in log-resistivity space:

$$m_j = \log_{10}\rho_j$$

Benefits:

  • Naturally enforces positivity: \(\rho_j = 10^{m_j} > 0\)
  • Matches the scale of variations (multiplicative)
  • Improves numerical conditioning
  • Symmetric treatment of increases/decreases

8.3 Bounds Constraints

Physical bounds ensure realistic resistivities:

$$0.1 \leq \rho_j \leq 10000 \text{ Ω·m}$$

This covers the full range of Earth materials:

  • 0.1-10 Ω·m: Saltwater, graphite, massive sulfides
  • 10-100 Ω·m: Clays, shales, wet sediments
  • 100-1000 Ω·m: Sandstones, limestones
  • 1000-10000 Ω·m: Crystalline rocks, dry sediments

8.4 Convergence Criteria

The optimization terminates when:

  1. Function tolerance: \(\frac{|\Phi_{k+1} - \Phi_k|}{\Phi_k} < 10^{-6}\)
  2. Parameter tolerance: \(\|\mathbf{m}_{k+1} - \mathbf{m}_k\| < 10^{-6}\)
  3. Maximum iterations: \(k > 50 \times M\)

9.3 Model Uncertainty and Resolution

Important caveat: Smooth inversion provides the simplest model that fits the data, not necessarily the "true" Earth structure.

Resolution decreases with depth:

  • Shallow layers (<100 m): Well-resolved by high-frequency data
  • Mid-depth (100-1000 m): Moderate resolution
  • Deep layers (>1000 m): Poorly resolved, increasingly smooth

Non-uniqueness: Multiple models may fit the data equally well. Smooth inversion chooses the smoothest among them.

10. Summary and Recommendations

10.1 Workflow

  1. Run Bostick first: Fast initial check
  2. Run smooth inversion: Get optimized model
  3. Compare results: Assess 1D validity and model reliability
  4. Use smooth inversion for interpretation: Better fit, more reliable depths

10.2 When to Trust Each Method

Scenario Recommendation
Both methods agree, low RMS ✓ Excellent - confident 1D interpretation
Models similar, smooth inversion has lower RMS ✓ Use smooth inversion model
Models very different ⚠ Check data quality, consider 2D/3D effects
Both methods have high RMS (>0.5) ✗ 1D assumption likely invalid, need 2D inversion
