3. Formatos de Datos

Crucial   Archivo .usf

Universal Sounding Format — Formato estándar para datos de sondeos eléctricos.

Contiene:

//PROJECTIdentificador del informe
//EPSGSistema de coordenadas (25830)
//ARRAYConfiguración de electrodos
/LOCATIONCoordenadas UTM (X, Y, Z)
/DATEFecha de adquisición
/AZIMUTHDirección del tendido
SPACING, RESISTIVITYCurva de resistividad aparente (AB/2 vs ρa)
Este es el archivo imprescindible. Contiene los datos observados originales (curva de campo) y las coordenadas de cada sondeo.

Importante   Archivo .mdl

Modelo 1D de capas — Resultado de la interpretación original del SEV.

Contiene:

FIDATOSID del sondeo
CORX, CORY, CORZCoordenadas (duplica .usf)
CAPANúmero de capa (3–10 capas)
RESISTIVIDADResistividad de cada capa (Ω·m)
ESPESOREspesor de cada capa (m)
Es la base ideal para el modelo inicial 3D. La última capa no tiene espesor (semiespacio). Solo disponible en 315 de 317 sondeos.

6. Paso 1 — Extracción y Parseo

6.1 Descomprimir todo

import os, zipfile, re

base = "SEV_SIGEOF"
output = "extracted"

for folder in os.listdir(base):
    folder_path = os.path.join(base, folder)
    if not os.path.isdir(folder_path): continue
    for zf in os.listdir(folder_path):
        if zf.endswith(".zip"):
            with zipfile.ZipFile(os.path.join(folder_path, zf)) as z:
                z.extractall(os.path.join(output, folder))

6.2 Parsear archivos .usf

def parse_usf(filepath):
    """Retorna dict con metadatos y curva de resistividad aparente."""
    data = {"meta": {}, "curve": []}
    with open(filepath) as f:
        in_data = False
        for line in f:
            line = line.strip()
            if line.startswith("//EPSG:"):
                data["meta"]["epsg"] = line.split(":")[1].strip()
            elif line.startswith("/LOCATION:"):
                parts = line.split(":", 1)[1].split(",")
                data["meta"]["x"] = float(parts[0])
                data["meta"]["y"] = float(parts[1])
                data["meta"]["z"] = float(parts[2])
            elif line.startswith("/SOUNDING_NAME:"):
                data["meta"]["name"] = line.split(":", 1)[1].strip()
            elif line.startswith("INDEX"):
                in_data = True; continue
            elif in_data and line == "/END":
                in_data = False
            elif in_data:
                parts = line.split(",")
                ab2 = float(parts[1])
                rho_a = float(parts[2])
                data["curve"].append((ab2, rho_a))
    return data

6.3 Parsear archivos .mdl

def parse_mdl(filepath):
    """Retorna dict con coordenadas y modelo de capas."""
    data = {"layers": []}
    with open(filepath) as f:
        for line in f:
            if "CORX:" in line:
                data["x"] = float(re.search(r"CORX:\s+([\d.]+)", line).group(1))
                data["y"] = float(re.search(r"CORY:\s+([\d.]+)", line).group(1))
            parts = line.split()
            if len(parts) >= 2 and parts[0].isdigit():
                rho = float(parts[1])
                thickness = float(parts[2]) if len(parts) == 3 else None
                data["layers"].append({
                    "rho": rho,
                    "thickness": thickness  # None = semiespacio
                })
    return data

7. Paso 2 — Diseño de la Malla ModEM

ModEM utiliza una malla de diferencias finitas con celdas en coordenadas cartesianas (x, y, z). La malla debe cubrir toda la isla de Mallorca con padding suficiente para evitar efectos de borde.

7.1 Dimensiones recomendadas

ParámetroValor sugeridoJustificación

(UTM 30N, ETRS89)		 Centro aproximado del área cubierta por los SEVs
Zona central (celdas finas) ~80 km × 60 km Cubre la extensión de los datos (66.8 × 49.9 km) con margen
Tamaño celda horizontal
(zona central)		 1 – 2 km Resolución razonable dada la densidad de sondeos (~317 puntos en ~4,000 km²)
Padding horizontal 7–10 celdas por lado, factor de crecimiento 1.3–1.5 La malla debe extenderse al menos 3× la profundidad máxima de investigación en cada dirección
Profundidad primera capa ~50 m Compatible con la resolución somera de los SEV
Capas verticales 25–35 capas, crecimiento logarítmico Desde ~50 m hasta ~50–100 km, con factor de crecimiento ~1.2–1.3
Profundidad total ~100 km Suficiente para el semiespacio en datos DC

7.2 Script de generación de malla

import numpy as np

# --- Zona central ---
dx_core = 1500  # m, tamaño celda horizontal
nx_core = 54    # celdas en X (~81 km)
ny_core = 40    # celdas en Y (~60 km)

# --- Padding horizontal ---
n_pad = 8
pad_factor = 1.4
pad_x = [dx_core * pad_factor**i for i in range(1, n_pad + 1)]

dx = pad_x[::-1] + [dx_core]*nx_core + pad_x
dy = pad_x[::-1] + [dx_core]*ny_core + pad_x

# --- Capas verticales (crecimiento logarítmico) ---
dz_first = 50     # primera capa
n_z = 30
z_factor = 1.25
dz = [dz_first * z_factor**i for i in range(n_z)]

print(f"Malla: {len(dx)} x {len(dy)} x {len(dz)} celdas")
print(f"Extensión total X: {sum(dx)/1000:.1f} km")
print(f"Extensión total Y: {sum(dy)/1000:.1f} km")
print(f"Profundidad total: {sum(dz)/1000:.1f} km")

8. Paso 3 — Modelo Inicial de Resistividades

Estrategia clave: Los archivos .mdl proporcionan modelos 1D ya interpretados. La idea es interpolar estos modelos en la malla 3D para obtener un modelo inicial mucho más realista que un semiespacio homogéneo.

8.1 Convertir modelos 1D a perfiles de profundidad

def mdl_to_depth_profile(mdl_data, z_centers):
    """Convierte modelo 1D de capas a perfil de resistividad
    en las profundidades centrales de la malla."""
    layers = mdl_data["layers"]
    rho_profile = np.zeros(len(z_centers))

    # Calcular profundidades de interfaces
    interfaces = [0]
    for layer in layers:
        if layer["thickness"] is not None:
            interfaces.append(interfaces[-1] + layer["thickness"])
        else:
            interfaces.append(1e6)  # semiespacio

    # Asignar resistividad a cada profundidad
    for iz, zc in enumerate(z_centers):
        for il, layer in enumerate(layers):
            if interfaces[il] <= zc < interfaces[il + 1]:
                rho_profile[iz] = layer["rho"]
                break

    return rho_profile

8.2 Interpolación espacial

Para cada celda (i, j) de la malla horizontal, el modelo inicial se construye así:

Opción A — Vecino más cercano: Asignar el perfil 1D del sondeo más próximo. Simple, pero genera discontinuidades.

Opción B — Distancia inversa ponderada (IDW): Promediar los perfiles 1D cercanos ponderados por 1/d². Produce transiciones más suaves.

Opción C — Kriging: Interpolación geoestadística. La mejor opción si la distribución de sondeos lo permite, pero requiere un variograma previo.

from scipy.spatial import cKDTree
from scipy.interpolate import RBFInterpolator

# Coordenadas de los sondeos con .mdl
sev_coords = np.array([[s["x"], s["y"]] for s in all_mdl_data])
sev_profiles = np.array([mdl_to_depth_profile(s, z_centers) for s in all_mdl_data])

# Interpolación IDW para cada profundidad
tree = cKDTree(sev_coords)

def idw_interpolate(x, y, z_idx, k=6, power=2):
    dists, idxs = tree.query([x, y], k=k)
    if dists[0] == 0:
        return sev_profiles[idxs[0], z_idx]
    weights = 1.0 / dists**power
    weights /= weights.sum()
    return np.dot(weights, sev_profiles[idxs, z_idx])

# Construir modelo 3D
model_3d = np.zeros((len(dz), len(dy_core_centers), len(dx_core_centers)))
for iz in range(len(dz)):
    for iy, yc in enumerate(y_centers):
        for ix, xc in enumerate(x_centers):
            model_3d[iz, iy, ix] = idw_interpolate(xc, yc, iz)
Importante: Trabajar en log(resistividad) para la interpolación. Las resistividades varían en órdenes de magnitud (4 – 2300 Ω·m en tus datos), así que interpolar en escala logarítmica produce resultados físicamente más coherentes.

Nota sobre los datos SEV para ModEM: Los SEV (corriente continua) son sensibles solo a la resistividad, no a la fase. ModEM está diseñado originalmente para MT (magnetotelúrica), así que necesitarás adaptar los datos. La estrategia más directa es usar las curvas de resistividad aparente de los .usf como datos de entrada, simulando "pseudofrecuencias" basadas en las distancias AB/2 (skin depth equivalente). Alternativamente, puedes usar solo los modelos .mdl para construir el modelo inicial y luego correr una inversión forward/constrained.

9.2 Conversión SEV → pseudo-MT

# Conversión aproximada AB/2 → periodo equivalente
# Skin depth: δ = 503 * sqrt(ρ * T)
# Si AB/2 ≈ δ, entonces T ≈ (AB/2)² / (503² * ρ)

def ab2_to_period(ab2, rho_a):
    """Aproximación del periodo MT equivalente."""
    return (ab2**2) / (503**2 * rho_a)

10. Recomendaciones y Precauciones

Puntos fuertes de estos datos

Buena cobertura espacial de la isla (~317 puntos en ~67×50 km). Los modelos 1D interpretados (.mdl) ya disponibles ahorran mucho trabajo. El formato USF es estándar y bien documentado. La configuración Schlumberger es robusta para exploración de resistividades. Las profundidades de investigación alcanzan hasta 1.4 km en algunos puntos.

Limitaciones a tener en cuenta

El 87% de los sondeos carecen de dato de elevación (Z = -9999). Necesitarás un DEM de Mallorca para asignar topografía. La distribución espacial no es homogénea; habrá zonas con poca cobertura. Los datos son de 1971–1985, así que no reflejan cambios recientes (intrusión salina, urbanización). La conversión SEV → formato ModEM no es trivial, ya que ModEM fue diseñado para MT.

Consideración crítica sobre ModEM y datos DC: ModEM está optimizado para datos magnetotelúricos (impedancias complejas en dominio de frecuencia). Los datos SEV son mediciones de corriente continua con geometría Schlumberger. La conversión no es directa y puede introducir artefactos. Si tu objetivo final es un modelo 3D de resistividades de Mallorca, considera seriamente usar frameworks de inversión pensados para datos DC como pyGIMLi, SimPEG, o BERT, que manejan nativamente la física de los SEV. Si la inversión en ModEM es un requerimiento estricto (por ejemplo, para combinar después con datos MT reales), entonces el modelo inicial basado en los .mdl será especialmente crucial para compensar las limitaciones de la conversión.
