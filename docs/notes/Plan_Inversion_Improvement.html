⚠ Root Cause Diagnosis

The inversion converged at RMS ≈ 20.7 after 50 iterations (target: 1.0–2.0). The damping parameter λ stayed at 100 for ALL 50 iterations and never decreased. This means the model was heavily over-regularized — the regularization penalty dominated the objective function and the model could barely deviate from the starting 100 Ω·m half-space. The restart criterion (RMS diff < 0.002) was never triggered because RMS was still decreasing at ~0.02/iteration at the end — a rate above the threshold, but far too slow to reach the target.

Fix Inversion Control Parameters

Critical
ModEM_config/invCtrl_mallorca

This is the single most impactful change. The damping parameter λ controls the trade-off between data fit and model smoothness. At λ=100, the regularization completely dominates and the model has almost no freedom to fit the data.

Parameter Current New Reasoning
Initial λ 100 10 λ=100 is far too high. Starting at 10 gives the model freedom to evolve while maintaining regularization stability.
λ divide by 10 5 Smaller divisor = more gradual λ reduction = more stable convergence. Steps: 10 → 2 → 0.4 → ...
Restart RMS diff 2.0e-3 5.0e-2 Current threshold (0.002) is too tight — requires RMS to essentially stop changing. With 0.05, λ reduces when convergence slows significantly.
Search step 20 10 Smaller initial step for more stable line search behaviour with lower λ.
Max iterations 50 200 50 was not enough. With proper λ reduction, 100–200 iterations needed for full convergence through multiple λ stages.
Target RMS 1.05 1.5 1.05 is very ambitious for 3D MT with real data. Start with 1.5 as a realistic first goal.

Increase Covariance Smoothing

Critical
ModEM_config/3D_Grid/covariance.cov

With lower λ, the model has more freedom and needs additional smoothing to prevent artifacts. Increasing from 0.2 to 0.3 provides a good balance — 0.3 is a standard value in ModEM practice.

Parameter Current New Reasoning
X smoothing (all layers) 0.2 0.3 Standard value; compensates for lower λ to prevent model artifacts.
Y smoothing (all layers) 0.2 0.3 Same as X for isotropic horizontal smoothing.
Vertical smoothing 0.2 0.3 Vertical stability needs same increase.
Smoothing passes 2 2 Keep at 2 (standard for ModEM).

Edit lines 20–22 of covariance.cov: replace all 0.2 values with 0.3.

Re-process Data: Add Tipper + Review Error Floors

Important
ModEM_config/3D_Grid/mall_Z.dat

Current state: 5% error floor, Full Impedance only (no tipper).

Tipper data (Tx, Ty) is confirmed available in the EDI files. Including it provides complementary sensitivity to lateral conductivity contrasts and significantly improves 3D imaging quality.

Changes needed:

  1. Include tipper data (Tx, Ty) — Re-run 3D_Grid_Academic selecting Full Impedance + Tipper.
  2. Off-diagonal impedance error floor (Zxy, Zyx): Keep at 5% — this is standard practice.
  3. Diagonal impedance error floor (Zxx, Zyy): Increase to 10–20% — diagonal components are noisier and shouldn't dominate the misfit.
  4. Tipper error floor: Set to 0.03 absolute — standard for tipper transfer functions.

Action: Re-run 3D_Grid_Academic with the settings above to regenerate mall_Z.dat.

Data Quality Control

Important

Before re-running the inversion, review the data quality:

  1. Remove noisy frequencies: Check EDI files for the highest and lowest frequencies. AMT data at extreme frequencies often has poor quality. Trim the frequency range if the highest/lowest bands show scattered data.
  2. Station QC: Check if any of the 41 stations have consistently poor data quality (high scatter in apparent resistivity curves, phase going outside 0–90° range). Consider excluding the worst 2–3 stations.
  3. Reduce number of frequencies: The current 58 frequencies may include redundant information. Consider decimating to ~15–20 well-distributed periods (4–5 per decade). This reduces computation time per iteration significantly while preserving resolution.

Grid Refinement

Optional

Current grid: 67×67×50, core cell 200m. Only apply if Phases 1–4 don't reach the target RMS.

  • Reduce core cell size to 100m in the area of station coverage for better lateral resolution.
  • Add more vertical layers near surface (5m first layer instead of 10m) for improved shallow structure resolution.
  • Ensure padding extends at least 3× the maximum skin depth in all directions to avoid boundary effects.

Note: This will increase computation time significantly.

Execution Strategy

Run 1: Fix Controls

Phases 1 + 2 only
  1. Edit invCtrl_mallorca with new parameters
  2. Edit covariance.cov to use 0.3 smoothing
  3. Keep same data file and starting model
  4. Submit to MAGMA (200 iters, 3 days)
  5. Verify: λ should decrease during the run

Run 2: Better Data

If Run 1 RMS > 5
  1. Re-process with 3D_Grid_Academic (tipper + error floors)
  2. Remove noisy stations/frequencies
  3. Include tipper data
  4. Use best model from Run 1 as starting model
  5. Submit new inversion

Run 3: Refine Grid

If Run 2 RMS > 3
  1. Refine the mesh (100m core cells)
  2. Use layered starting model from 1D results
  3. Final inversion run

✔ Verification Checklist

  1. Check the .log file: verify λ is decreasing across iterations
  2. Plot RMS vs iteration: should show clear step-downs when λ reduces
  3. Compare observed vs predicted data in the final .dat output
  4. Visualize the resulting resistivity model (.rho files) at different depth slices
  5. Target: RMS < 2.0 with geologically reasonable model structure
