1. Introducción a MTpy

¿Qué es MTpy?

MTpy (Magnetotelluric Python) es una biblioteca profesional de código abierto diseñada específicamente para el procesamiento, análisis y modelado de datos magnetotelúricos.

Ventajas de usar MTpy:

  • ✅ Lectura robusta de archivos EDI con manejo automático de unidades
  • ✅ Análisis profesional del tensor de impedancia
  • ✅ Herramientas de inversión 1D, 2D y 3D
  • ✅ Análisis de dimensionalidad geológica
  • ✅ Visualización avanzada de datos MT
  • ✅ Integración con códigos de modelado profesional (ModEM, Occam)
⚠️ Diferencia con análisis manual:
Un parser manual solo extrae datos brutos y calcula resistividad aparente. MTpy realiza análisis completo del tensor de impedancia, correcciones, rotaciones, y proporciona modelos del subsuelo.

2. Inversión 1D - Transformación Bostick

2.1. ¿Qué es la Inversión 1D?

La inversión 1D es un proceso matemático que convierte datos de resistividad aparente (medida en superficie) en un modelo de capas del subsuelo con resistividades reales a diferentes profundidades.

Concepto clave:

  • 📊 Dato de entrada: Resistividad aparente vs frecuencia
  • 🎯 Resultado: Resistividad real vs profundidad (modelo de capas)
  • 📐 Asunción: Capas horizontales infinitas (modelo 1D)
ℹ️ Nota importante:
Una inversión formal (Occam1D, ModEM) requiere software especializado externo. En este análisis usamos la Transformación Bostick, que es una aproximación rápida y analítica que proporciona resultados razonables sin necesidad de software externo.

2.2. Pasos Seguidos para la Inversión 1D

1 Lectura de datos con MTpy

Se utiliza la clase MT() de MTpy para leer el archivo EDI:

from mtpy.core.mt import MT mt_obj = MT() mt_obj.read('mall67.edi')

MTpy automáticamente:

  • Lee el archivo EDI completo
  • Extrae el tensor de impedancia Z (componentes Zxx, Zxy, Zyx, Zyy)
  • Maneja las conversiones de unidades [mV/km]/[nT] → Ω
  • Calcula resistividades aparentes y fases

2 Obtención de resistividades aparentes

MTpy proporciona las resistividades ya calculadas correctamente:

# Obtener tensor de impedancia Z = mt_obj.Z # Resistividades aparentes (MTpy maneja las unidades) rho_xy = Z.resistivity[:, 0, 1] # Modo TE rho_yx = Z.resistivity[:, 1, 0] # Modo TM # Promedio geométrico (aproximación Bostick) rho_avg = sqrt(rho_xy * rho_yx)

3 Cálculo de profundidad de penetración (Skin Depth)

La profundidad característica a la que penetra la señal electromagnética:

δ = 503 × √(ρ / f) donde: δ = profundidad de penetración (skin depth) [m] ρ = resistividad aparente promedio [Ω·m] f = frecuencia [Hz] 503 = constante derivada de √(1/(π·μ₀·σ))

Interpretación física: A esta profundidad, la amplitud de la señal electromagnética ha disminuido a 1/e (~37%) de su valor en superficie.

4 Transformación Bostick

Conversión de resistividad aparente a resistividad real del subsuelo:

# Calcular derivada logarítmica d(log ρ) / d(log T) donde T = 1/f es el período # Resistividad Bostick (real) ρ_real(z) = ρ_aparente × [1 + d(log ρ) / d(log T)] # Profundidad Bostick z_Bostick = δ / √2

Fundamento teórico: La transformación Bostick relaciona la derivada de la resistividad aparente con la resistividad real a una profundidad característica.

⚠️ Limitación de valores extremos:
Para evitar valores negativos o físicamente imposibles, se limita la derivada: d(log ρ) / d(log T) ∈ [-0.8, 2.0]

5 Interpretación de capas

Se identifican capas principales buscando cambios significativos en resistividad:

  • Cambios donde log₁₀(ρ₂/ρ₁) > 0.3 indican fronteras de capas
  • Se clasifican según rangos típicos de resistividad
Resistividad (Ω·m) Interpretación Geológica
< 10 Arcillas saturadas / Sedimentos conductivos
10 - 50 Sedimentos / Rocas alteradas
50 - 200 Rocas sedimentarias / Calizas
200 - 1000 Rocas consolidadas
> 1000 Basamento resistivo

3. Análisis de Dimensionalidad

3.1. ¿Qué es el Análisis de Dimensionalidad?

El análisis de dimensionalidad determina la complejidad geométrica de las estructuras geológicas del subsuelo:

Dimensión Descripción Ejemplo Geológico
1D Variación solo con profundidad
Capas horizontales infinitas		 Cuenca sedimentaria de capas planas
2D Variación en profundidad + 1 dirección horizontal
Estructura elongada		 Fallas, diques, valles, cordilleras
3D Variación en las 3 direcciones
Estructura compleja		 Intrusiones, domos salinos, zonas de fractura
ℹ️ ¿Por qué es importante?
Saber la dimensionalidad permite:
  • ✅ Elegir el método de inversión apropiado (1D, 2D o 3D)
  • ✅ Reducir ambigüedad en la interpretación
  • ✅ Optimizar recursos computacionales (modelo más simple posible)
  • ✅ Determinar si se necesita rotación del tensor de impedancia

3.2. Pasos Seguidos para el Análisis de Dimensionalidad

1 Método 1: Skew de Swift

El skew mide la asimetría del tensor de impedancias.

Skew = |Zxx + Zyy| / |Zxy - Zyx| donde: Zxx, Zyy = elementos diagonales del tensor de impedancia Zxy, Zyx = elementos off-diagonal del tensor de impedancia

Criterios de clasificación:

  • Skew < 0.2: Estructura 1D o 2D simple
  • 0.2 ≤ Skew < 0.4: Estructura 2D con efectos 3D
  • Skew ≥ 0.4: Estructura 3D compleja
📊 Resultados Skew:
  • Mínimo: 0.059
  • Máximo: 1.670
  • Media: 0.263
  • Mediana: 0.162
Clasificación: 2D con efectos 3D
Interpretación: Estructura principalmente 2D con heterogeneidades laterales

2 Método 2: Ratio Diagonal / Off-diagonal

En una estructura 1D/2D ideal, los elementos diagonales (Zxx, Zyy) deben ser mucho menores que los off-diagonal (Zxy, Zyx).

Magnitud_diagonal = √(|Zxx|² + |Zyy|²) Magnitud_off-diagonal = √(|Zxy|² + |Zyx|²) Ratio = Magnitud_diagonal / Magnitud_off-diagonal

Criterios de clasificación:

  • Ratio < 0.2: Estructura 1D/2D bien orientada
  • 0.2 ≤ Ratio < 0.5: Estructura 2D, posible rotación necesaria
  • Ratio ≥ 0.5: Estructura 3D o 2D mal orientada
📊 Resultados Ratio:
  • Mínimo: 0.106
  • Máximo: 1.306
  • Media: 0.366
  • Mediana: 0.290
Clasificación: 2D
Interpretación: Estructura 2D con posible rotación necesaria

3 Método 3: Elipticidad de la Fase (β)

La elipticidad mide la diferencia entre las fases de los componentes xy e yx.

β = (φ_xy - φ_yx) / 2 donde: φ_xy = fase del componente Zxy [grados] φ_yx = fase del componente Zyx [grados]

Criterios de clasificación:

  • |β| < 5°: Estructura 1D (capas horizontales)
  • 5° ≤ |β| < 15°: Estructura 2D (elongada)
  • |β| ≥ 15°: Estructura 3D (compleja)
📊 Resultados Elipticidad:
  • Mínima: -89.83°
  • Máxima: 89.88°
  • Media: 5.73°
  • Mediana: 60.53°
Clasificación: 2D
Interpretación: Estructura elongada con dirección preferencial

4 Síntesis de Resultados

Se combinan los resultados de los tres métodos mediante votación:

Método Clasificación
1. Skew de Swift 2D con efectos 3D
2. Ratio Diagonal/Off-diagonal 2D
3. Elipticidad de la Fase 2D

Lógica de votación: Si 2 o más métodos coinciden en una dimensión, esa es la dimensionalidad dominante.

3.3. Resultados del Análisis de Dimensionalidad

✅ DIMENSIONALIDAD DOMINANTE: 2D

Los tres métodos independientes coinciden en que la estructura geológica en la estación mall67 es predominantemente bidimensional (2D).

Implicaciones Geológicas:

🗺️ Estructura 2D significa:
  • ✅ Existe una dirección preferencial en las estructuras geológicas
  • ✅ No son simplemente capas horizontales (que sería 1D)
  • ✅ Posibles causas:
    • Fallas o zonas de fractura orientadas
    • Estratos inclinados o plegados
    • Diques o intrusiones elongadas
    • Contactos litológicos con orientación preferencial

Recomendaciones para Modelado:

📋 Próximos pasos recomendados:
  1. Determinar el strike angle (dirección principal de la estructura 2D)
  2. Rotar el tensor de impedancia al sistema de coordenadas del strike
  3. Realizar inversión 2D en la dirección perpendicular al strike
  4. Considerar múltiples estaciones para perfiles 2D completos
