Magnetotelluric Dimensionality Analysis

Mathematical Documentation and Interpretation Guide

1. Introduction: The Dimensionality Problem in MT

1.1 What is Dimensionality?

In magnetotellurics, dimensionality refers to the geometric complexity of the subsurface electrical resistivity structure. Understanding dimensionality is crucial because it determines:

  • What type of modeling approach is appropriate (1D, 2D, or 3D)
  • Whether data rotation is necessary
  • How to interpret off-diagonal vs diagonal impedance elements
  • The computational cost of inversion

1.2 Three Types of Structures

Dimensionality Structure Description Geological Examples Impedance Tensor
1D Resistivity varies only with depth. Properties are uniform horizontally. Sedimentary basins, oceanic crust, horizontally layered stratigraphy \(Z_{xx} = Z_{yy} = 0\)
\(Z_{xy} = -Z_{yx}\)
2D Resistivity varies with depth and one horizontal direction. Elongated structures. Mountain ranges, subduction zones, major faults, dikes After rotation to strike:
\(Z_{xx} = Z_{yy} = 0\)
\(Z_{xy} \neq -Z_{yx}\)
3D Resistivity varies in all three spatial directions. Complex geometry. Salt domes, ore bodies, volcanic systems, complex fault networks All four elements non-zero:
\(Z_{xx}, Z_{xy}, Z_{yx}, Z_{yy} \neq 0\)

1.3 The Impedance Tensor

Recall that the MT impedance tensor relates electric and magnetic fields:

$$\begin{bmatrix} E_x \\ E_y \end{bmatrix} = \begin{bmatrix} Z_{xx} & Z_{xy} \\ Z_{yx} & Z_{yy} \end{bmatrix} \begin{bmatrix} H_x \\ H_y \end{bmatrix}$$

The impedance tensor components carry information about subsurface geometry:

  • Off-diagonal elements (\(Z_{xy}, Z_{yx}\)): Dominant in 1D and 2D structures
  • Diagonal elements (\(Z_{xx}, Z_{yy}\)): Should be zero in 1D, small in 2D, significant in 3D
Key Insight: Dimensionality analysis examines the relative magnitudes and relationships between these impedance tensor components to classify the structure.

2. Method 1: Swift Skew

2.1 Mathematical Definition

The Swift skew (Swift, 1967) is defined as:

$$\text{Skew} = \frac{|Z_{xx} + Z_{yy}|}{|Z_{xy} - Z_{yx}|}$$

where \(Z_{ij}\) are the complex impedance tensor elements.

2.2 Physical Interpretation

The skew measures the asymmetry of the impedance tensor:

  • Numerator \(|Z_{xx} + Z_{yy}|\): Sum of diagonal elements (should be zero for 2D)
  • Denominator \(|Z_{xy} - Z_{yx}|\): Difference of off-diagonal elements (non-zero for 2D)

2.3 Classification Thresholds

Threshold Values and Rationale

Skew Range Interpretation Physical Meaning
Skew < 0.2 1D or 2D structure Diagonal elements are <20% of off-diagonal. Structure is simple.
0.2 ≤ Skew < 0.4 2D with 3D effects Some asymmetry present. Might be 2D with lateral heterogeneities.
Skew ≥ 0.4 3D structure Significant diagonal elements. Complex 3D geometry required.
Why these limits?
  • 0.2 threshold: Empirically determined from synthetic 1D/2D models. Diagonal elements contribute <20% suggests negligible 3D effects.
  • 0.4 threshold: When diagonal elements reach 40% of off-diagonal, 3D modeling becomes necessary for accurate interpretation.

2.4 Code Implementation

# Extract impedance components Zxx = Z.z[:, 0, 0] # Diagonal element (x,x) Zxy = Z.z[:, 0, 1] # Off-diagonal (x,y) Zyx = Z.z[:, 1, 0] # Off-diagonal (y,x) Zyy = Z.z[:, 1, 1] # Diagonal element (y,y) # Calculate Swift skew numerator = np.abs(Zxx + Zyy) denominator = np.abs(Zxy - Zyx) skew = numerator / denominator # Classification skew_mean = np.nanmean(skew) if skew_mean < 0.2: dimension = "1D/2D" elif skew_mean < 0.4: dimension = "2D with 3D effects" else: dimension = "3D"

3. Method 2: Diagonal vs Off-Diagonal Ratio

3.1 Mathematical Definition

This method compares the magnitude of diagonal elements to off-diagonal elements:

$$\text{Ratio} = \frac{\sqrt{|Z_{xx}|^2 + |Z_{yy}|^2}}{\sqrt{|Z_{xy}|^2 + |Z_{yx}|^2}}$$

This is the ratio of the norm of diagonal elements to the norm of off-diagonal elements.

3.2 Physical Interpretation

In a 1D or properly-oriented 2D structure:

  • Diagonal elements \(Z_{xx}\) and \(Z_{yy}\) should be zero
  • Off-diagonal elements \(Z_{xy}\) and \(Z_{yx}\) contain all the signal
  • Therefore, the ratio should be small

A large ratio indicates:

  • 3D structure, OR
  • 2D structure that is not aligned with the measurement coordinates (needs rotation)

3.3 Classification Thresholds

Threshold Values and Rationale

Ratio Range Interpretation Physical Meaning
Ratio < 0.2 1D or well-oriented 2D Diagonal elements are <20% of off-diagonal magnitude.
0.2 ≤ Ratio < 0.5 2D, possibly misoriented Diagonal elements present but moderate. May need coordinate rotation.
Ratio ≥ 0.5 3D or badly misoriented 2D Diagonal elements comparable to off-diagonal. Complex structure.
Why these limits?
  • 0.2 threshold: If diagonal elements are <20%, they can be considered negligible compared to measurement uncertainty (~5-10%).
  • 0.5 threshold: When diagonal elements reach 50% of off-diagonal, the structure is either truly 3D or severely misoriented. At this point, 2D assumption fails.

3.4 Code Implementation

# Calculate magnitudes of diagonal components mag_diag = np.sqrt(np.abs(Zxx)**2 + np.abs(Zyy)**2) # Calculate magnitudes of off-diagonal components mag_offdiag = np.sqrt(np.abs(Zxy)**2 + np.abs(Zyx)**2) # Calculate ratio ratio_diag = mag_diag / mag_offdiag # Classification ratio_mean = np.nanmean(ratio_diag) if ratio_mean < 0.2: dimension = "1D/2D" elif ratio_mean < 0.5: dimension = "2D" else: dimension = "3D"

  • Depth-dependent complexity: Does 3D character vary with depth?
  • Need for rotation: High ratio with low skew suggests misorientation

4. Method 3: Phase Tensor Ellipticity

4.1 Mathematical Definition

The phase tensor approach (Caldwell et al., 2004) separates galvanic distortion from inductive response. The ellipticity parameter \(\beta\) is derived from the phase difference between modes:

$$\beta = \frac{1}{2}(\phi_{xy} - \phi_{yx})$$

where \(\phi_{xy}\) and \(\phi_{yx}\) are the phases of the off-diagonal impedance elements:

$$\phi_{xy} = \arg(Z_{xy}) = \arctan\left(\frac{\text{Im}(Z_{xy})}{\text{Re}(Z_{xy})}\right)$$

4.2 Physical Interpretation

The ellipticity \(\beta\) represents:

  • \(\beta = 0\): Perfect 1D structure (phases are equal)
  • \(\beta \neq 0\): 2D or 3D structure (phase split between modes)
  • |\(\beta\)| large: Strong dimensionality (2D/3D effects)
Advantage of Phase Tensor: The phase is less affected by galvanic distortion (surface conductivity anomalies) than apparent resistivity. This makes \(\beta\) a more robust indicator of deeper structure geometry.

4.3 Classification Thresholds

Threshold Values and Rationale

|\(\beta\)| Range Interpretation Physical Meaning
|\(\beta\)| < 5° 1D structure Phase difference negligible. Horizontal layers dominate.
5° ≤ |\(\beta\)| < 15° 2D structure Moderate phase split. Elongated geological feature present.
|\(\beta\)| ≥ 15° 3D structure Large phase asymmetry. Complex 3D geometry.
Why these limits?
  • 5° threshold: Below 5°, phase difference is within typical measurement uncertainty (2-3° for good data). Structure is effectively 1D.
  • 15° threshold: Above 15°, the phase tensor becomes strongly asymmetric, indicating substantial lateral resistivity variations characteristic of 3D structures.
  • Theoretical basis: For a 2D structure, \(\beta\) should be constant (doesn't vary with frequency). Frequency-dependent \(\beta\) suggests 3D.

4.4 Code Implementation

# Extract phases from impedance phase = Z.phase # MTpy calculates this internally phase_xy = phase[:, 0, 1] # Phase of Z_xy phase_yx = phase[:, 1, 0] # Phase of Z_yx # Calculate phase difference (handle wrapping at ±180°) phase_diff = phase_xy - phase_yx phase_diff = np.where(phase_diff > 180, phase_diff - 360, phase_diff) phase_diff = np.where(phase_diff < -180, phase_diff + 360, phase_diff) # Calculate ellipticity (beta) beta = phase_diff / 2.0 # Classification beta_mean = np.abs(np.nanmean(beta)) if beta_mean < 5: dimension = "1D" elif beta_mean < 15: dimension = "2D" else: dimension = "3D"

Interpretation Patterns

\(\beta\) > 15° and variable 3D structure. Phase tensor shows complex asymmetry.
Caution: Very high ellipticity (|\(\beta\)| > 30°) at isolated frequencies may indicate data problems rather than true 3D structure. Check data quality at those periods.

5. Method 4: Strike Angle Analysis

5.1 Mathematical Definition

For a 2D structure, there exists a strike angle \(\theta\) that defines the direction of geological elongation. The strike is calculated using Swift's method:

$$\theta = \frac{1}{2} \arctan\left(\frac{2\text{Re}(Z_{xy} + Z_{yx})}{|Z_{xx}|^2 - |Z_{yy}|^2}\right)$$

After rotation by angle \(\theta\), the impedance tensor becomes:

$$\mathbf{Z}' = \mathbf{R}(-\theta) \mathbf{Z} \mathbf{R}(\theta)$$

where \(\mathbf{R}(\theta)\) is the rotation matrix:

$$\mathbf{R}(\theta) = \begin{bmatrix} \cos\theta & \sin\theta \\ -\sin\theta & \cos\theta \end{bmatrix}$$

5.2 Physical Interpretation

The strike angle represents:

  • Geological strike: Direction parallel to elongated geological features
  • Coordinate rotation: Angle to rotate measurement axes to align with structure
  • 2D consistency: Constant strike across frequencies confirms 2D structure

5.3 Strike Angle Conventions

Convention: Strike angle is measured clockwise from North (geographic convention) and is constrained to [0°, 90°] due to 180° ambiguity in MT data.
Strike Angle Geological Orientation Example
0° North-South Mid-Atlantic Ridge, Rocky Mountains (N-S trending)
45° NE-SW San Andreas Fault (NW-SE, complementary angle)
90° East-West Himalayan front (E-W trending)

5.4 Strike Variability Analysis

Standard Deviation Thresholds

Strike Std Dev Interpretation Implication
σ < 10° Well-defined 2D structure Strike is consistent across all depths. Clear 2D geometry.
10° ≤ σ < 30° 2D with complications Generally 2D but with depth-varying strike or local 3D effects.
σ ≥ 30° 3D or poorly defined 2D No consistent strike direction. Structure is likely 3D.
Why these limits?
  • 10° threshold: Within ±10°, strike is well-constrained. This is the typical uncertainty in strike determination for good 2D data.
  • 30° threshold: Variation >30° means strike changes significantly with frequency/depth, which violates the 2D assumption of a single strike direction.

5.5 Code Implementation

# Calculate strike angle using Swift's method numerator = 2 * np.real(Zxy + Zyx) denominator = np.abs(Zxx)**2 - np.abs(Zyy)**2 # Calculate strike in radians, then convert to degrees pt_strike = 0.5 * np.arctan2(numerator, denominator + 1e-10) * 180 / np.pi # Normalize to [0, 90] degrees range pt_strike = np.where(pt_strike < 0, pt_strike + 90, pt_strike) pt_strike = np.where(pt_strike > 90, pt_strike - 90, pt_strike) # Analyze strike consistency pt_std = np.nanstd(pt_strike) pt_mean = np.nanmean(pt_strike) if pt_std < 10: interpretation = f"Well-defined 2D strike at ~{pt_mean:.1f}°" elif pt_std < 30: interpretation = "2D structure with variable strike" else: interpretation = "3D structure (no consistent strike)"

6. Plot 5: Apparent Resistivity Reference

6.1 Purpose of This Plot

This plot shows the observed apparent resistivity data (TE and TM modes) as a reference. It helps contextualize the dimensionality indicators by showing:

  • Data quality and consistency
  • TE-TM mode splitting (indicator of 2D/3D)
  • Overall resistivity structure

6.2 TE and TM Modes

Definition:
  • TE mode (Transverse Electric): \(\rho_{xy}\) - Electric field perpendicular to strike
  • TM mode (Transverse Magnetic): \(\rho_{yx}\) - Magnetic field perpendicular to strike

In 2D structures, these modes respond differently:

$$\rho_{xy}^{\text{TE}} = \frac{|Z_{xy}|^2}{\omega\mu_0}, \quad \rho_{yx}^{\text{TM}} = \frac{|Z_{yx}|^2}{\omega\mu_0}$$

6.3 Plot Description

What the Plot Shows

  • X-axis: Period (s) in logarithmic scale
  • Y-axis: Apparent resistivity (Ω·m) in logarithmic scale
  • Blue curve: TE mode (\(\rho_{xy}\))
  • Red curve: TM mode (\(\rho_{yx}\))

Information Extracted

  • Mode splitting: Separation between TE and TM curves
    • No splitting → 1D structure
    • Constant splitting → 2D structure
    • Variable splitting → 3D effects
  • Resistivity trends:
    • Increasing with period → resistivity increases with depth
    • Decreasing with period → resistivity decreases with depth
    • Oscillating → layered structure with alternating resistivity
  • Data quality: Smooth curves indicate good data; jumps suggest noise

TE-TM Splitting Patterns

Splitting Pattern Dimensionality Physical Meaning
TE ≈ TM (overlapping curves) 1D Both modes see the same layered structure
TE > TM (TE curve above TM) 2D conductive structure TE mode sees higher resistivity (perpendicular to conductor)
TM > TE (TM curve above TE) 2D resistive structure TM mode sees higher resistivity (perpendicular to resistor)
Curves cross multiple times 3D or complex layering Mode behavior changes with depth; not simple 2D
Integration with Dimensionality: Use this plot together with dimensionality indicators. For example:
  • If skew is low but TE-TM splitting is large → Structure is 2D but coordinate system needs rotation
  • If skew is high and curves cross → Confirms 3D structure
  • If all dimensionality indicators are low and TE ≈ TM → Confirms 1D interpretation

7. Integrated Decision Framework

7.1 Decision Tree for Dimensionality

Step-by-Step Dimensionality Determination
  1. Check Swift Skew
    • If mean skew < 0.2 → Go to Step 2
    • If mean skew ≥ 0.4 → Conclude: 3D structure
    • If 0.2 ≤ mean skew < 0.4 → Go to Step 3
  2. Check Diagonal Ratio (if skew < 0.2)
    • If ratio < 0.2 → Conclude: 1D or well-oriented 2D
    • If 0.2 ≤ ratio < 0.5 → Check strike consistency (Step 4)
    • If ratio ≥ 0.5 → Go to Step 3
  3. Check Ellipticity (if skew or ratio are moderate)
    • If |\(\beta\)| < 5° → Conclude: 1D
    • If 5° ≤ |\(\beta\)| < 15° and constant → Conclude: 2D, proceed to Step 4
    • If |\(\beta\)| ≥ 15° or highly variable → Conclude: 3D
  4. Check Strike Angle (if 2D is indicated)
    • If strike std dev < 10° → Conclude: Excellent 2D, strike = {mean}°
    • If 10° ≤ std dev < 30° → Conclude: 2D with complexity
    • If std dev ≥ 30° → Re-evaluate as 3D
  5. Check TE-TM Splitting
    • Consistent with dimensionality conclusions? → Confirm
    • Contradicts other indicators? → Check data quality

7.3 Frequency-Dependent Dimensionality

Important Consideration: Dimensionality can vary with frequency (depth). Common scenarios:
  • Shallow 1D, Deep 2D: Sedimentary cover (1D) over basement fault (2D)
  • Shallow 3D, Deep 1D: Near-surface heterogeneity over uniform basement
  • Shallow 2D, Deep 3D: Linear mountain range over complex deep structure
Solution: If dimensionality changes with frequency, consider:
  • Separate inversions for different frequency ranges
  • 3D inversion to capture full complexity
  • Hybrid approach: 1D/2D for specific depth ranges

8.2 Common Pitfalls and How to Avoid Them

Pitfall 1: Relying on a single indicator
  • Problem: One indicator might be misleading due to noise or local effects
  • Solution: Always use all four methods and look for consensus
Pitfall 2: Ignoring frequency dependence
  • Problem: Average values may hide depth-varying dimensionality
  • Solution: Examine plots carefully for trends with period
Pitfall 3: Forcing 2D when data shows 3D
  • Problem: 2D inversion of 3D data produces artifacts
  • Solution: If multiple indicators suggest 3D, accept it and use 3D modeling
Pitfall 4: Over-interpreting noisy data
  • Problem: Bad data at a few frequencies can skew interpretations
  • Solution: Apply data quality filters (as in the code) before analysis
